## 📖 About the Project

**Gaganyaan** (Sanskrit: *"Sky Craft"*) is India's flagship Human Spaceflight Programme — an ambitious mission to carry Indian astronauts to Low Earth Orbit using entirely indigenous technology. This website is a **fan-made educational concept experience** built from ISRO's publicly available mission data, designed to make the mission's engineering and human story accessible and beautiful.

From the thunderous liftoff of the **Human-Rated LVM3 (HLVM3)** to the quiet splashdown in Indian seas, every section of this site walks you through the mission the way it will unfold.

> *Built with respect for the scientists of the Indian Space Research Organisation.* 🇮🇳

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌌 **Animated Starfield** | A fully custom canvas starfield with parallax depth, twinkle physics and subtle drift — rendered in real time. |
| 🧨 **Exploded Rocket View** | The HLVM3 separates into its six stages on scroll. **Hover or tap any stage** (CES → CM → SM → C25 → L110 → S200) to read its engineering brief. |
| 📊 **Mission Data Cards** | Key mission parameters — crew size, 400 km orbit, mission duration, and the 640 t lift-off mass of India's heaviest rocket. |
| 👨‍✈️ **The Crew** | Profiles of the four IAF Group Captain astronaut-designates — and **Vyommitra**, ISRO's half-humanoid robot astronaut flying the uncrewed qualification missions. |
| 📱 **Fully Responsive** | Desktop uses a sticky stage-inspector layout; mobile gets a native-feeling swipeable stage carousel. |
| 🎞️ **Scroll-Reveal Motion** | Buttery section reveals powered by the Intersection Observer API. |
| 🪟 **Glassmorphism UI** | Frosted-glass panels with neon accents in cosmic cyan, saffron and India green. |

## 🛠️ Tech Stack

- **[React 18](https://react.dev/)** — UI components (loaded via CDN, no build step required)
- **[Tailwind CSS](https://tailwindcss.com/)** — utility-first styling with a custom `cosmic` color palette
- **Canvas API** — procedural starfield with parallax + twinkle
- **SVG** — hand-drawn, interactive exploded rocket diagram
- **Babel Standalone** — in-browser JSX transpilation
- **Google Fonts** — *Space Grotesk* & *Inter*

## 🚀 Getting Started

This is a **zero-dependency, no-build** project. Just open the file:

```bash
# 1. Clone the repository
git clone https://github.com/Benin07/GAGANYAAN-Concept-Website.git

# 2. Open index.html in any modern browser
cd GAGANYAAN-Concept-Website
```

Or simply double-click `index.html` — everything (React, Tailwind, Babel) is served from CDN, so an internet connection is all you need.
